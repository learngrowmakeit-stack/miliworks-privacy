### Enable GitHub Pages

1. In this repository, open Settings → Pages.
2. Source: Deploy from a branch.
3. Branch: main; folder: / (root); click Save.
4. Wait for the Pages deployment to complete.
5. Open https://learngrowmakeit-stack.github.io/miliworks-privacy/ without a
   GitHub login before using it as the Privacy policy URL in Play Console.

The repository must be public on a GitHub plan that only supports public Pages.
Only this policy and its artwork are included; application source and signing
keys remain in the separate application repository.
